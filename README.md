# Olayinka Shehu — Investigative Journalism Portfolio

An editorial-style, mobile-responsive portfolio for investigative journalism and digital research.

## Before publishing
- Confirm that the listed publication names accurately reflect your bylines.
- Add verified links to individual articles, with headline, outlet, publication date, and a short summary. No article URLs have been invented.
- Review the biography and preferred pronouns.
- Check that all project summaries are accurate and safe to disclose.
- The email and LinkedIn links have been set to the details provided.
- Do not upload passwords, private source data, unpublished sensitive evidence, or confidential documents. A public repository is visible to everyone.

## Publish for free with GitHub Pages
1. Sign in at https://github.com/ or create an account.
2. Create a **public** repository named `YOUR-GITHUB-USERNAME.github.io`, replacing the placeholder with your actual GitHub username.
3. Upload `index.html` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for deployment. The site should appear at `https://YOUR-GITHUB-USERNAME.github.io`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
